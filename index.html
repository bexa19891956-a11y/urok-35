📚 Домашнее задание — JavaScript

Задание 1

Математические примеры

Введите имя и возраст. Затем решите 5 примеров (+, −, ×, ÷, остаток). Все ответы запишутся в консоль разработчика.

Задание 2

Среднее арифметическое X, Y, Z

Введите три числа через prompt(). Программа найдёт среднее арифметическое и выведет через alert().

Задание 3

Проверка возраста

Введите возраст. Программа выведет сообщение: молоды / работать / скоро пенсия / пенсионер.

Задание 4

Время суток (switch)

Введите час от 0 до 23. Программа определит время суток через оператор switch.

Задание 5

Среднее из трёх чисел

Введите 3 числа. Программа найдёт число, которое находится между наименьшим и наибольшим.

Задание 6

Случайный чек (receipt)

Функция receipt() возвращает случайный набор товаров. Нажмите, чтобы сгенерировать чек.
